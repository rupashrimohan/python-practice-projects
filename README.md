# Python Crash Course Practice Projects

This repository contains my personal practice code and exercises completed while reading **Python Crash Course** by Eric Matthes. It serves as a record of my learning journey through the fundamental concepts of Python.


## Repository Structure

The code is organized by the topics covered in the book:

- **Variables and Data Types:** Working with strings, numbers, and basic math.
- **Lists and Tuples:** Creating, modifying, sorting, and looping through lists.
- **If Statements:** Conditional tests and logical operations.
- **Dictionaries and sets:** Storing and accessing key-value pairs.
- **User Input and While Loops:** Making interactive programs.
- **Functions:** Passing arguments, returning values and using modules.
- **Classes:** Object-Oriented Programming (OOP) and inheritance.
- **Files and Exceptions:** Reading/writing files and handling errors.
- **Testing Code:** Writing basic tests using `pytest`.


## Requirements

To run the scripts in this repository, you will need:
- [Python 3.x](https://www.python.org/downloads/) installed on your machine.
